# {{project_name}}

This project was generated by `switchyard init`. Its deployment starts empty so you can
declare the repositories, source worktrees, startup profiles, instances, and groups that
belong to this project.

Validate and inspect the project before starting it:

```sh
switchyard validate deployment.yaml
switchyard plan deployment.yaml
switchyard up deployment.yaml
switchyard status deployment.yaml
switchyard down deployment.yaml
```

Edit `deployment.yaml` to add repositories once, then add ordinary worktrees under
`sources:` as `{ repository, ref, path }`. `switchyard up` creates missing repository
stores and source worktrees before starting instances. Runtime and generated state is
kept under `.switchyard/`.

Codex-compatible agents can use the project-local `$switchyard-project` skill under
`.agents/skills/` for the safe edit, validation, lifecycle, and recovery workflow.
